# AI Interview Assistant

A Streamlit app using Groq's free-tier API to generate interview questions, evaluate answers, and practice coding interviews.

## Deploy
1. Upload `app.py` and `requirements.txt` to a GitHub repository.
2. Create a Streamlit Community Cloud app pointing at `app.py`.
3. In the app's Secrets settings, add `GROQ_API_KEY = "your_key_here"`.
4. Deploy. Groq free-tier usage limits apply.

Do not commit API keys or candidate personal data.
